## 📌 Como Renomear a URL para `h-maker` no GitHub:

Para que o endereço do seu site seja **`https://michelroger.github.io/h-maker/`**, siga este passo simples:

1. Acesse o seu repositório no GitHub: **[https://github.com/michelroger/m3d](https://github.com/michelroger/m3d)**.
2. Clique na aba **Settings** (Configurações do Repositório).
3. No topo da página em **Repository Name**, troque `m3d` por **`h-maker`** e clique em **Rename**.
4. Pronto! O GitHub atualizará automaticamente o link do seu site para:
   **`https://michelroger.github.io/h-maker/`**

## 🔄 Como Atualizar o Site no Futuro

Sempre que fizer novas alterações no código ou adicionar peças no catálogo:

```bash
# 1. Adicionar e commitar as alterações
git add .
git commit -m "update: novas peças e melhorias"

# 2. Enviar para o GitHub
git push origin main

# 3. Publicar no GitHub Pages
npm run deploy
```
